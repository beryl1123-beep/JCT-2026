# 第二幕「廿载长卷」设计记录

## 目标

第一幕改为自然纵向上滑进入第二幕，不再通过点击整屏触发墨晕切场。第二幕以水墨山水长卷承载 2006–2026 演艺时间线，并继续复用现有 Markdown 资料格式。

## 交互结构

1. 第一幕占满一屏，底部只保留“向上滑动”提示。
2. 第二幕占满一屏，横向长卷宽度大于视口，可拖动或使用触控板浏览。
3. 每个年份在山脊附近显示为发光节点，节点位置有高低变化，形成沿山势前进的节奏。
4. 点击年份后，以宣纸卷轴对话框展示对应 Markdown 中的事件卡片。
5. 事件卡片支持横向滑动；每张卡包含时间、图片、简述和资料链接。

## 内容数据

年份内容保存在 `content/scene2-layer2/*.md`，页面运行时读取并解析。图片路径仍遵循现有命名规则；缺图时使用具有年份标记的“影像待审”占位，方便审查阶段逐张替换。

本轮根据百度百科演艺经历补齐 2007、2008、2010、2011、2012、2013 六个缺失年份，并将其加入前端年份映射。

## 视觉方向

第二幕采用深青黑夜色、青绿山水与少量暖金光点。用户提供的 `SecondPage-background.PNG` 作为核心山体，不额外改变素材本身；上层加入呼吸光点、暗角和宣纸纹理，让第二幕既延续第一幕的水墨感，也开始向最终的星河场景过渡。

## 验证标准

- 桌面端和移动端都能自然上滑进入第二幕。
- 2006–2026 共 21 个年份节点均能出现。
- 每个年份都能打开对应资料文件，资料缺图不会造成破图。
- 卷页可关闭，横向浏览和键盘焦点状态可用。
- 尊重系统“减少动态效果”设置。

## 视觉审查修订

- 山水素材只铺设一次，并按原图 4000×1080 的横向比例生成长卷，不再循环。
- 年份改用显式 `x / y` 坐标贴合新图山脊，后续可逐年微调。
- 年份光点核心色与第一幕“檀健次”文字统一为 `#c9a84c`，保留青绿色外晕。
- 原生详情弹窗内增加一套顶层水墨光标，避免弹窗遮罩盖住主页光标。
- 缺图事件自动切换为纯文字卡片，不再展示空白图片框或破图。
- CSS、JS 与第二幕背景图均使用同一版本参数刷新浏览器缓存。
