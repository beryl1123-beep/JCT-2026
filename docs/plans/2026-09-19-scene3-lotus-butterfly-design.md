# 第三幕：莲开蝶至

## 交互目标

- 第三幕沿用前两幕同一张纸纹背景，页面本身保持透明，保证纵向衔接不换色。
- 初始画面直接叠加原始花叶透明分层，复原原型图 1 的聚拢构图。
- 六朵花依次可点亮；未点亮花朵保持柔和的朱红呼吸光，点亮后转为稳定光晕并记录进度。
- 六朵花全部点亮后，花朵沿弧线向下、向两侧舒展，落到原型图 3 的底部位置；三组叶片同时退到画面下方并淡出。
- 动画结束后出现朱砂水墨蝴蝶。蝴蝶先以收翼比例轻轻振翅飞入，点击后展开为完整双翼展示。
- 提供“重聚”按钮，便于原型审查时反复查看两种状态。

## 视觉与动效

- 交互文字克制地放在上方留白，不遮挡花叶主体。
- 花朵光晕采用朱砂红与暖金叠加，保持与水墨素材一致，不使用霓虹蓝绿。
- 每朵花使用独立位移、旋转与延迟，避免六张图像机械地同时直线下落。
- 蝴蝶使用透明底朱砂水墨素材，CSS 负责振翅、飞入和展开，减少额外图像依赖。

## 响应式与可访问性

- 花叶分层以同一 1904×1080 设计画布为坐标系，宽高变化时整体同步缩放。
- 小屏幕保持底部花阵完整可见，并缩小顶部说明文字。
- 六个花朵热区均为可聚焦按钮，带有状态标签；支持键盘操作和减少动态效果偏好。

## 第二轮交互与性能修订

- 原始花叶分层仍保留，但网页改用按透明边界裁切后的轻量副本，坐标按 1904×1080 画布比例还原；避免九张全屏透明图长期占用显存。
- 花朵持续发光从大图滤镜动画改为小尺寸点击光环，第二、三幕离开视口时暂停循环动画。
- 花朵完成前仅使用一只侧视朱砂蝶。它以低频随机目的地和 CSS transform 飞行，点击花朵时短暂停落，不使用逐帧 GIF。
- 第六朵花点亮后，花阵与蝴蝶同步变换：花朵下落、叶片退场、蝴蝶直接展开，随后出现六个可点击光点。
- 点击光点后，蝴蝶和光点组左移，未选光点及背景压暗；右侧滑入复用第二幕卷轴纹理的内容面板，可切换光点或收卷。
